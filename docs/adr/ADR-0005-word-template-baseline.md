# ADR-0005 — Modèle Word professionnel comme baseline documentaire

Statut : Accepted

## Décision

Le fichier DOTX du Sprint 004.3 devient le point de départ des rapports A.D.C.
rédigés manuellement. Il consomme l'identité officielle et les extensions
fonctionnelles du Design System 004.1.

## Hors périmètre

- moteur d'assemblage automatique ;
- intégration MecaAI ;
- automatisation des propriétés personnalisées ;
- bibliothèque complète de blocs réutilisables.
