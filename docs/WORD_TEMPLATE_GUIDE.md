# ADC Professional Report Template 0.4.3

## Objet

Ce modèle Word applique l'identité A.D.C. validée :
logo officiel, bleu `#0054A6`, gris `#8C8C8C`, Montserrat pour les titres
et Aptos pour la lecture longue.

## Utilisation

1. Ouvrir le fichier `.dotx`.
2. Créer un nouveau document à partir du modèle.
3. Remplacer les données de couverture et d'identité.
4. Utiliser les styles Word fournis.
5. Mettre à jour la table des matières.
6. Exporter en PDF et contrôler visuellement chaque page.

## Styles principaux

- ADC Cover Title
- ADC Cover Subtitle
- ADC Lead
- ADC Caption
- ADC Code
- ADC Appendix
- Titre 1, Titre 2 et Titre 3 personnalisés

## Composants présents

- Couverture
- Page d'identité
- Historique des révisions
- Diffusion
- Table des matières
- Synthèse exécutive
- Constat
- Recommandation
- Risque
- Décision
- Tableau technique
- Code et journal
- Annexes

## Limite du logo

Le logo présent dans ce sprint est extrait de la charte PDF fournie. Il sert
de référence exploitable. Lorsqu'un SVG ou PNG transparent original sera
disponible, il devra remplacer cet extrait sans modifier les proportions.
