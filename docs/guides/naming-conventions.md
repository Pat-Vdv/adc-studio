# Conventions de nommage

## Documents

Format recommandé :

```text
ADC-<TYPE>-<ANNEE>-<NUMERO>
```

Exemples :

```text
ADC-IR-2026-001
ADC-AR-2026-001
ADC-PR-2026-001
ADC-IN-2026-001
```

## Types

- `IR` : rapport d’intervention ;
- `AR` : rapport d’audit ;
- `PR` : rapport projet ou architecture ;
- `IN` : rapport d’incident ;
- `CR` : compte rendu.

## Fichiers

Utiliser des noms courts, explicites et sans donnée sensible.
