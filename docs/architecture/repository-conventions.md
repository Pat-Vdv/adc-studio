# Repository Conventions

## components/

Un identifiant C-xxx correspond à un seul composant.

## profiles/

Les profils décrivent la composition documentaire.

## templates/

Contient uniquement les sources éditables.

## reference_reports/

Contient les profils et ressources servant de référence aux rapports.

## examples/

Documents d'exemple destinés à illustrer l'utilisation.

## tests/

Tests automatiques et jeux de validation.

## design/

Identité graphique, ressources visuelles et tokens.

## docs/

Documentation d'architecture et guides.

## tools/

Outillage de développement uniquement.
