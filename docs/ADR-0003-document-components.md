# ADR-0003 — Bibliothèque de composants

Statut : Accepted

Chaque rapport ADC est composé d'une suite de composants indépendants.

Composants du noyau :
- Cover
- Executive Summary
- Context
- Findings
- Risks
- Recommendations
- Timeline
- Version History
- Annexes

Objectif : réutilisation maximale et homogénéité graphique.
