## Phase 4 — Automatisation

L’automatisation ne démarre qu’après validation du framework manuel.

Objectifs envisagés :

- génération de rapports à partir de données structurées ;
- assemblage automatique des composants ;
- versionnage des composants utilisés ;
- intégration future avec MecaAI ;
- génération PowerPoint dans une phase ultérieure.
