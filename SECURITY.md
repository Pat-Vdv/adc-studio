# Règles de confidentialité

Ne jamais ajouter :

- noms de clients réels ;
- adresses e-mail ou coordonnées ;
- numéros de TVA ;
- noms de serveurs ou adresses IP réelles ;
- captures d'écran de production ;
- journaux techniques réels ;
- mots de passe, tokens ou clés ;
- rapports d'intervention clients ;
- configurations d'infrastructure.

Tous les exemples présents dans ce dépôt doivent être fictifs ou anonymisés.
