# ADC Design Language v0.1

## Devise

> Observer. Vérifier. Démontrer. Documenter.

## Style rédactionnel

Privilégier les formulations factuelles :

❌ « Le serveur semble planter »

✅ « Le serveur cesse de répondre après environ 1 h 25 lors de l'exécution de DBCC CHECKDB. Le comportement est reproductible. »

## Classification des affirmations

- Fait observé
- Mesure
- Déduction
- Hypothèse
- Décision

## Palette (provisoire)

- Bleu principal : #0054A6
- Gris : #6B7280
- Vert validation : #2E7D32
- Orange attention : #F59E0B
- Rouge critique : #C62828
